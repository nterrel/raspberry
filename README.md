# Raspberry microserver

I couldn't think of a better way to backup my user configuration files and programs written on Raspberry Pi Zero W (v1.1)

## Bash Files

- `.bash_aliases`: User-defined (nick's) aliases
- `.bash_history`: Not publishing that one lol
- `.bash_logout`: Script that runs on logout, haven't modified but might in the future.
- `.bashrc`: My interactive shell configuration script
- `.profile`: Script that configures login shells
